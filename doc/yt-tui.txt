*yt-tui.txt*  Open YouTrack in a floating terminal

==============================================================================
INTRODUCTION                                                       *yt-tui*

yt-tui.nvim runs the yt-tui executable in a centered floating terminal.
Requires Neovim 0.11+ and yt-tui on PATH (or an explicit executable path).
The application continues to manage its own credentials and configuration.

COMMANDS                                                   *yt-tui-commands*

:YtTui [arguments]                                                  *:YtTui*
    Open yt-tui. Arguments are passed directly to the executable, after any
    configured defaults. An issue URL can be supplied to open it directly.
    Without arguments, focus an existing running session. Close it before
    supplying different arguments. If the old process failed, start again.

:YtTuiClose                                                    *:YtTuiClose*
    Stop the process and close its window and buffer.

KEYS                                                           *yt-tui-keys*

The plugin sets no global mappings. The example lazy.nvim configuration maps
<leader>yy to :YtTui.

Terminal-mode keys go to yt-tui. Use CTRL-\ CTRL-N to leave terminal mode,
then q or <Esc> to close the floating terminal. Closing stops the process;
reopening starts a fresh session. Successful exits close automatically.
Unsuccessful exits retain their terminal output for inspection.

The buffer sets b:terminal_passthrough before TermOpen. User configurations
can check this flag when installing terminal mappings such as kj.

CONFIGURATION                                                *yt-tui-setup*
>
    require("yt-tui").setup({
      executable = "yt-tui",
      args = {},
      width = 0.9,
      height = 0.9,
      border = "rounded",
      title = " yt-tui ",
    })
<
width and height are fractions greater than zero and at most one. The window
is centered and resizes with Neovim. border accepts built-in border style
names such as rounded, single, double, solid, shadow, and none. Highlights
follow the active colorscheme.

executable is a single executable name or path, without flags. Use
vim.fn.expand() for paths containing ~. args is a list of strings. Arguments
are never evaluated by a shell.

Calling setup again resets unspecified options to defaults. Changes apply
to the next session. Setup is optional when using the defaults.

LUA API                                                        *yt-tui-api*
>
    require("yt-tui").open()
    require("yt-tui").open({ "https://youtrack.example.com/issue/PROJ-123" })
    require("yt-tui").close()
<
open returns true on launch/focus, or false after notifying about a failure.

The process inherits Neovim's working directory and environment. External
editors launched by yt-tui run inside its terminal; exit the editor to return
to yt-tui. There is no remote-editor bridge or hidden-session persistence.
